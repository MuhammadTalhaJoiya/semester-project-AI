Evaluation Metrics

Confusion Matrix

Shows True/False Positives and Negatives. Visual representation of model performance.

ROC Curve & AUC

Receiver Operating Characteristic curve. AUC shows model's ability to distinguish classes.

Classification Report

Detailed metrics: Precision, Recall, F1-score for each class. Provides comprehensive analysis.

Cross-Validation

5-fold CV ensures model robustness. Reduces overfitting risk and validates generalizability.

Accuracy

Overall correctness: (TP + TN) / Total

Precision

True Positives / (TP + FP) - How many predicted positives are actually positive

Recall

True Positives / (TP + FN) - How many actual positives are found

F1-Score

Harmonic mean of Precision and Recall - Balanced metric
